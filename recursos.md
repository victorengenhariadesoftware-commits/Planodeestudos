## 🗃️ Datasets Recomendados para o Projeto

Para obter a melhor experiência ao longo dos 30 dias, utilize preferencialmente uma **base transacional de vendas**:

1. **Superstore Sales Dataset (Kaggle):**
   - *Descrição:* Base clássica de vendas de varejo, contendo informações de pedidos, clientes, categorias de produtos, regiões, vendas, custos e descontos.
   - *Link:* [Kaggle - Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
2. **Brazilian E-Commerce Public Dataset by Olist (Kaggle):**
   - *Descrição:* Dados reais e anonimizados de 100 mil pedidos no Brasil, excelente para modelagem relacional com múltiplas tabelas (clientes, pedidos, pagamentos, itens, produtos).
   - *Link:* [Kaggle - Olist E-Commerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
3. **AdventureWorks (Microsoft Sample):**
   - *Descrição:* Base padrão da Microsoft para testes em SQL e Power BI.
   - *Link:* [Microsoft Learn - AdventureWorks](https://learn.microsoft.com/sql/samples/adventureworks-install-configure)
