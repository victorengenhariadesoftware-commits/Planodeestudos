\#\# Estratégia de uso dos materiais

Não tente concluir todos os cursos ou materiais durante os 30 dias. Use-os como apoio para o conteúdo previsto no \`cronograma.md\`.

A regra principal é:

\> aprender um conceito → praticar → aplicar no projeto de vendas → registrar nas anotações.

\#\# Projeto integrado

Sempre que possível, utilize a mesma base de vendas durante as quatro semanas. Isso permitirá observar como cada ferramenta resolve partes diferentes do mesmo problema:

\- Excel para exploração inicial  
\- SQL para consultas  
\- Power Query para preparação  
\- Power BI/DAX para indicadores e dashboard  
\- Python para análise complementar

Ao concluir uma semana, registre no arquivo de anotações quais materiais realmente ajudaram, quais foram difíceis e quais merecem revisão futura.
