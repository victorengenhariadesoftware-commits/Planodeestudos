> Um plano prático de 30 dias para desenvolver fundamentos em **Análise de Dados e Business Intelligence**, integrando Excel, SQL, Power BI e Python em um único projeto de portfólio.

---

## 🎯 Objetivo

Desenvolver uma base prática para começar a atuar em **Análise de Dados / Business Intelligence**, aprendendo a:

- coletar dados;
- organizar informações;
- consultar bases;
- limpar e transformar dados;
- construir indicadores;
- analisar resultados;
- criar dashboards;
- comunicar insights.

Ao final dos 30 dias, o objetivo é construir um pequeno projeto de portfólio seguindo uma esteira completa de análise:

```text
Dados Brutos
    ↓
Tratamento
    ↓
Análise
    ↓
Indicadores
    ↓
Dashboard
    ↓
Conclusões
````

---

## 🧭 Trilha de Aprendizagem

A ordem de estudo foi estruturada para que cada ferramenta complemente a anterior.

| Etapa | Tecnologia      | Objetivo                             |
| :---: | --------------- | ------------------------------------ |
|   01  | 📗 **Excel**    | Explorar, organizar e analisar dados |
|   02  | 🗄️ **SQL**     | Consultar e manipular informações    |
|   03  | 📊 **Power BI** | Criar modelos, métricas e dashboards |
|   04  | 🐍 **Python**   | Automatizar e aprofundar análises    |

### Ordem recomendada

```text
Excel
  ↓
SQL
  ↓
Power Query
  ↓
Power BI + DAX
  ↓
Python
```

> [!IMPORTANT]
> A proposta não é estudar ferramentas isoladas, mas entender como elas podem funcionar juntas dentro de um processo real de análise de dados.

# 🚀 Projeto Final

Durante os 30 dias, será utilizada preferencialmente **uma mesma base de dados**, como uma base de vendas.

A ideia é acompanhar os mesmos dados por diferentes etapas e ferramentas.

## 📗 Excel

Utilizado para:

* exploração inicial da base;
* tabelas;
* fórmulas;
* tabelas dinâmicas;
* gráficos;
* indicadores iniciais.

---

## 🗄️ SQL

Utilizado para:

* consultar os dados;
* filtrar informações;
* realizar agregações;
* responder perguntas de negócio;
* criar consultas reutilizáveis.

Exemplos de perguntas:

```text
Qual produto possui maior faturamento?

Qual região apresenta maior volume de vendas?

Qual foi o faturamento médio mensal?

Quais vendedores possuem melhor desempenho?
```

---

## 🔄 Power Query

Utilizado para:

* importar dados;
* remover inconsistências;
* alterar tipos de dados;
* tratar valores nulos;
* combinar tabelas;
* automatizar transformações.

---

## 📊 Power BI + DAX

Utilizado para:

* modelagem de dados;
* criação de relacionamentos;
* desenvolvimento de métricas;
* construção de KPIs;
* criação de dashboards interativos.

Exemplos de indicadores:

```text
Faturamento Total
Ticket Médio
Quantidade de Vendas
Margem
Crescimento %
Desempenho por Região
```

---

## 🐍 Python

Utilizado para complementar a análise utilizando principalmente:

* `Pandas`
* `Matplotlib`
* `Jupyter Notebook`

Aplicações:

* importação de dados;
* tratamento;
* exploração;
* agrupamentos;
* estatísticas descritivas;
* visualizações;
* identificação de padrões.
